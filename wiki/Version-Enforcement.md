# Version Enforcement

CI check and pre-commit hook that block changes to standards without a version bump.

## How It Works

Two enforcement layers prevent content changes without version bumps:

### 1. CI Workflow

A GitHub Actions workflow (`standards-version-check.yml`) runs on every PR. It compares the diff against a version manifest (`standards-versions.json`) and fails the PR if a standard's content changed without its version comment being bumped.

### 2. Local Pre-Commit Hook

A pre-commit hook (`standards/hooks/standards/pre-commit-version-check.sh`) provides fast local feedback before push. It checks staged files and blocks the commit if a version bump is missing.

### Version Manifest

The manifest file `.github/scripts/standards-versions.json` tracks all current standard versions. It is regenerated by `build-versions-manifest.sh` to stay in sync.

## Technical Notes

- Covers both standards (`.md` version comments) and hooks (`hook-version` comments)
- The manifest builder script scans all standards and hooks to extract versions
- Full documentation in `docs/version-enforcement.md`
